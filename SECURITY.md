# Security Policy

Maintainer: Priyanshu Kumar Thakur

Please report suspected vulnerabilities privately through GitHub Security Advisories for this repository. Do not open a public issue with exploit details, credentials, or personal data.

Include: affected version or commit, reproduction steps using only systems you own or are authorised to test, impact, and a suggested fix if known. Reports are reviewed on a best-effort basis; please allow reasonable time for a fix before public disclosure.

Supported versions: the latest release on the default branch.

See also `docs/SECURITY.md` for the detailed security notes.
